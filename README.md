# Portfolio Hafizuddin Ghani Ifkar

Portfolio React + Vite + Tailwind CSS.

## Jalankan lokal

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```

## Deploy

Project ini siap di-deploy ke Vercel. Import repository GitHub ini ke Vercel; framework akan terdeteksi sebagai Vite dan build command menggunakan `npm run build`.
